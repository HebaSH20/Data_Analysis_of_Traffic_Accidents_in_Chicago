# Data Analysis of Traffic Accidents in Chicago

## Overview

This project focuses on analyzing traffic accident data in Chicago using Python and Jupyter Notebook.

The analysis explores traffic crashes and related information to identify patterns, trends, and insights from the available data.

## Project Contents

* `Data_Analysis_of_Traffic_Accidents_in_Chicago.ipynb` — Jupyter Notebook containing the complete data analysis.
* `datasets/` — Dataset files used by the notebook. The original datasets are not included in this repository because of their large size.

## Analysis

The project includes:

* Data loading and preparation
* Data cleaning and preprocessing
* Exploratory data analysis
* Data visualization
* Analysis of traffic accident patterns
* Analysis of information related to people and vehicles involved in crashes
* Geographic analysis using Chicago geographic data

## Technologies and Libraries

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* GeoPandas

## Dataset

The datasets used in this project are large and are therefore not included in this GitHub repository.

The notebook expects the datasets to be placed in a folder named:

```text
datasets/
```

## How to Run

1. Download or clone this repository.
2. Place the required dataset files inside the `datasets/` folder.
3. Open `Data_Analysis_of_Traffic_Accidents_in_Chicago.ipynb` using Jupyter Notebook or JupyterLab.
4. Run the notebook cells in order.
